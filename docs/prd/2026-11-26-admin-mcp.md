# 어드민 MCP (Claude 커넥터) PRD

> 작성일: 2026-11-26
> 상태: 초안, 팀 리뷰 필요
> 대상: `apps/admin-mcp` (신규, Hono, Vercel)
> 관련 문서: `ogonggo-BE/docs/architecture/authentication.md` 3·7-3 절, `docs/admin-api-contract.md`

## 1. 배경

관리자들이 Claude 에서 오공고 관리자 데이터를 바로 물어보고 싶어 한다. "오늘 들어온 광고 문의 몇 건이야",
"검수 대기 공고 키워드 X 로 찾아줘" 같은 질문을 지금은 콘솔 화면을 열어 필터를 맞춰야 답할 수 있다.

MCP(Model Context Protocol) 서버를 두면 Claude(claude.ai 커넥터, Claude Code)가 관리자 API 를 tool 로
부를 수 있다. 이 문서는 그 서버를 **백엔드와 기존 프론트를 고치지 않고** 만드는 방법을 정한다.

## 2. 목표와 비목표

### 목표

1. claude.ai 조직 설정의 맞춤 커넥터로 URL 하나를 등록하면, 관리자가 **연결**을 눌러 로그인하고 바로 쓴다.
2. 관리자 콘솔과 같은 렛츠커리어 이메일·비밀번호로 로그인한다. 새 계정 체계(Google 등)를 들이지 않는다.
3. MCP 를 연결해도 그 사람의 관리자 콘솔 세션이 끊기지 않는다.
4. 사람(이메일) 단위로 쓸 수 있는 tool 을 부서별로 나누고, 누가 어떤 tool 을 불렀는지 로그에 남긴다.
5. BE(`ogonggo-api-user`, `ogonggo-api-admin`, core), 기존 앱(`web`, `admin`, `business`), 공유 패키지를
   고치지 않는다. Redis 등 새 저장소를 두지 않는다.

### 비목표 (이번 범위 밖)

- 쓰기 tool(역할 변경, 공개 여부 변경, 발송, 광고 계약 상태 변경 등). 1차는 **조회만** 연다. 쓰기는 사람
  단위 감사 기록이 BE 에 없으므로 별도 결정 후 연다.
- BE 에 사람 단위 감사 로그 남기기. 지금 BE 에는 서비스 계정만 보인다(6 절).
- 특정 사람의 MCP 연결을 즉시 끊기(토큰 단위 취소). 허용 목록에서 빼는 것으로 대신한다(5-4).

## 3. 왜 이 구조인가

현재 로그인 구조에서 확인한 사실:

| 사실                                                                                                                              | 근거                                            |
| --------------------------------------------------------------------------------------------------------------------------------- | ----------------------------------------------- |
| 관리자 콘솔은 렛츠커리어 SSO(`POST /api/v1/sso/authenticate`)로 LC 토큰을 받고 `POST /api/v1/auth/letscareer` 로 OG 토큰과 바꾼다 | `apps/admin/src/shared/api/letsCareerSignIn.ts` |
| 관리자 API 는 토큰을 발급하지 않고 `ADMIN`·`ACTIVE` 인지만 검사한다                                                               | BE `authentication.md` 7-3                      |
| OG-refresh 는 계정당 하나만 Redis 에 있다. 다시 로그인하면 이전 refresh 가 무효다                                                 | BE `authentication.md` 3                        |
| 재발급(`POST /api/v1/auth/token`)은 refresh 를 바꾸지 않고 access 만 준다                                                         | `apps/admin/src/shared/api/reissue.ts`          |

**각 관리자 계정으로 OG 토큰을 받으면 콘솔과 MCP 가 서로를 끊는다.** MCP 를 연결하는 순간 콘솔의 refresh 가
무효가 되고, 콘솔에 다시 로그인하면 MCP 의 refresh 가 무효가 된다. 그래서 역할을 나눈다.

- **사람 확인**: 렛츠커리어 SSO 만 부른다. 비밀번호가 맞는지만 확인하고 오공고 토큰 교환은 하지 않는다.
  그래서 그 사람의 오공고 세션(콘솔)은 그대로다.
- **API 호출**: MCP 전용 `ADMIN` 계정(서비스 계정) 하나로 한다. 오공고에 로그인하는 것은 MCP 서버뿐이다.

검토하고 버린 대안:

| 대안                              | 버린 이유                                                                                        |
| --------------------------------- | ------------------------------------------------------------------------------------------------ |
| 관리자 본인 계정으로 OG 토큰 교환 | 위의 콘솔·MCP 상호 로그아웃                                                                      |
| 부서별 공용 렛츠커리어 계정       | 비밀번호 공유, 같은 부서 안에서도 refresh 충돌, 사람 단위 기록 없음                              |
| Google Workspace 로그인           | 관리자들이 이미 가진 렛츠커리어 계정으로 충분하다. Google Cloud OAuth 클라이언트 운영이 늘어난다 |
| 부서별 고정 Client ID/Secret      | 사람 단위 구분이 없다                                                                            |
| BE 에 Spring AI MCP 서버          | BE 수정이 크고 관리자 API 배포 경계에 MCP 가 섞인다                                              |
| 내부 API 키(`X-Internal-Api-Key`) | `/api/v1/internal/**` 만 열려 관리자 API 를 부를 수 없다                                         |

## 4. 전체 흐름

```text
[연결] claude.ai 커넥터 ── DCR(/register) ──> admin-mcp
       claude.ai ── /authorize ──> 로그인 화면 (렛츠커리어 이메일·비밀번호)
            admin-mcp: 허용 목록에 있는 이메일인지 확인
            admin-mcp ── POST /api/v1/sso/authenticate ──> 렛츠커리어   (비밀번호 확인만)
            admin-mcp ── 302 redirect_uri?code=... ──> claude.ai
       claude.ai ── /token (code + PKCE verifier) ──> admin-mcp ── access/refresh(서명 JWT)

[사용] claude.ai ── POST /mcp (Bearer MCP access) ──> admin-mcp
            admin-mcp: 토큰 검증 → 허용 목록 재확인 → 부서의 tool 만 노출
            admin-mcp ── Bearer OG-access(서비스 계정) ──> ogonggo-api-admin
```

## 5. 상세 요구사항

### 5-1. OAuth 2.1 인가 서버 (admin-mcp 가 직접)

MCP 스펙(2025-06-18 authorization)과 claude.ai 맞춤 커넥터가 요구하는 것만 구현한다.

| 경로                                                           | 내용                                                                                            |
| -------------------------------------------------------------- | ----------------------------------------------------------------------------------------------- |
| `GET /.well-known/oauth-protected-resource` (`/mcp` 접미 포함) | RFC 9728. `resource`, `authorization_servers`                                                   |
| `GET /.well-known/oauth-authorization-server`                  | RFC 8414. `S256` PKCE, `none` 클라이언트 인증, `authorization_code`·`refresh_token`             |
| `POST /register`                                               | RFC 7591 DCR. 저장하지 않고 등록 내용을 서명한 값을 `client_id` 로 돌려준다                     |
| `GET /authorize`                                               | 요청을 검증하고 로그인 화면을 그린다                                                            |
| `POST /authorize`                                              | 로그인 처리 후 인가 코드와 함께 `redirect_uri` 로 보낸다                                        |
| `POST /token`                                                  | 코드 교환(PKCE 검증), refresh 교환                                                              |
| `POST /mcp`                                                    | Streamable HTTP. Bearer 가 없거나 틀리면 401 + `WWW-Authenticate: Bearer resource_metadata=...` |

- **무상태**: 클라이언트, 인가 코드, access/refresh 토큰 모두 서명 JWT(HS256, `ADMIN_MCP_JWT_SECRET`)다.
  용도(`typ`)와 대상(`aud`)을 넣어 서로 바꿔 쓰지 못하게 한다.
- **수명**: 인가 코드 5분, access 1시간, refresh 7일.
- **redirect URI 허용 목록**: DCR 로 아무 주소나 등록하면 피싱으로 코드를 가로챌 수 있다. 기본값은
  `https://claude.ai/api/mcp/auth_callback`, `https://claude.com/api/mcp/auth_callback` 와
  루프백(`http://localhost:*`, `http://127.0.0.1:*`, Claude Code 용)이다. `ADMIN_MCP_REDIRECT_URIS` 로 바꾼다.
- **인가 코드 재사용**: 저장소가 없어 5분 안의 재사용을 막지 못한다. PKCE verifier 없이는 교환할 수 없어 위험을
  받아들인다.

### 5-2. 로그인 화면

- 콘솔과 같은 렛츠커리어 이메일·비밀번호 폼 하나. 어느 서비스(`redirect_uri` 호스트)로 돌아가는지 보여준다.
- **허용 목록에 없는 이메일이면 렛츠커리어를 부르지 않는다.** 이 화면이 아무 렛츠커리어 계정의 비밀번호
  확인 창구가 되지 않게 하기 위함이다. 실패 문구는 목록에 없음과 비밀번호 틀림을 구분하지 않는다.
- 비밀번호는 SSO 호출에만 쓰고 저장하거나 로그에 남기지 않는다. 받은 LC 토큰도 쓰지 않고 버린다.
- SSO 의 `redirectUri` 는 콘솔의 콜백 주소(`https://admin.ogonggo.co.kr/auth/letscareer/callback`)를 쓴다.
  콘솔도 그 주소로 이동하지 않고 화이트리스트 통과용 값으로만 쓴다. **렛츠커리어와 재사용 협의 필요.**
  `LETSCAREER_SSO_REDIRECT_URI` 로 바꿀 수 있다.

### 5-3. 서비스 계정

- MCP 전용 렛츠커리어 계정을 만들고 오공고에 한 번 로그인해 계정을 만든 뒤 콘솔에서 `ADMIN` 을 준다.
- 이메일·비밀번호는 Vercel 환경 변수(`OGONGGO_SERVICE_EMAIL`, `OGONGGO_SERVICE_PASSWORD`)에만 둔다.
- OG-access 는 함수 인스턴스 메모리에 둔다. 만료가 가까우면 refresh 로 재발급하고, 그것도 실패하면 다시 로그인한다.
  관리자 API 가 401 을 주면 한 번 갱신하고 다시 부른다. 동시에 들어온 요청은 갱신을 하나만 한다.
- 인스턴스마다 따로 로그인해도 된다. 새 로그인은 이전 refresh 만 무효로 하고, 이미 받은 access 는 만료까지 유효하다.
- **이 계정으로 콘솔이나 웹에 로그인하지 않는다.** 로그인하면 MCP 쪽 refresh 가 무효가 된다(재로그인으로 복구는 된다).

### 5-4. 허용 목록과 부서별 tool

`ADMIN_MCP_ACCESS` 환경 변수(JSON):

```json
{
  "departments": {
    "운영": ["*"],
    "영업": ["list_advertisement_inquiries", "get_advertisement_inquiry_today_count"]
  },
  "members": {
    "admin@example.com": "운영",
    "sales@example.com": "영업"
  }
}
```

- 이메일은 소문자로 비교한다. `*` 는 모든 tool 이다.
- 로그인, 토큰 갱신, MCP 요청마다 다시 확인한다. 목록에서 빼면 다음 요청부터 막힌다(배포 또는 환경 변수 반영 후).
- 콘솔에서 누군가의 `ADMIN` 을 빼도 MCP 는 이 목록을 따른다. 둘 다 빼야 한다.
- 급하게 모든 연결을 끊으려면 `ADMIN_MCP_JWT_SECRET` 을 바꾼다. 모두 다시 연결해야 한다.

### 5-5. 1차 tool (모두 조회, `readOnlyHint`)

| tool                                                                                                        | 관리자 API                                                                                    |
| ----------------------------------------------------------------------------------------------------------- | --------------------------------------------------------------------------------------------- |
| `list_jobs` / `get_job` / `list_today_jobs`                                                                 | `GET /jobs`, `GET /jobs/{jobId}`, `GET /jobs/today`                                           |
| `list_bootcamps` / `get_bootcamp`                                                                           | `GET /bootcamps`, `GET /bootcamps/{bootcampId}`                                               |
| `list_general_members` / `get_general_member`                                                               | `GET /general-members`, `GET /general-members/{userId}`                                       |
| `list_company_members` / `get_company_member`                                                               | `GET /company-members`, `GET /company-members/{userId}`                                       |
| `list_advertisement_inquiries` / `get_advertisement_inquiry_today_count`                                    | `GET /advertisement-inquiries`, `GET /advertisement-inquiries/today-count`                    |
| `list_advertisement_contracts` / `get_advertisement_contract` / `get_advertisement_contract_report_summary` | `GET /advertisement-contracts`, `GET /advertisement-contracts/{id}`, `GET .../report-summary` |
| `list_service_feedbacks`                                                                                    | `GET /service-feedbacks`                                                                      |
| `get_recent_notification_results`                                                                           | `GET /notifications/recent-results`                                                           |

- 경로 접두사는 모두 `/api/v1/admin`. 파라미터 enum 값은 생성 타입(`@ogonggo/api` admin models)과 같은지 타입으로 확인한다.
- 응답은 관리자 API 의 `data` 를 JSON 그대로 돌려준다. 오류는 상태 코드와 `code`·`message` 를 tool 오류로 돌려준다.
- 회원 tool 은 개인정보를 다룬다. 부서 tool 목록에서 필요한 부서만 준다.

### 5-6. 기록

- tool 호출마다 `{ email, department, tool, status, ms }` 를 구조화 로그(`console.info`)로 남긴다. 인자 값은 남기지 않는다.
- Vercel 로그 보관 기간이 짧다. 오래 남겨야 하면 로그 drain 을 붙인다(후속).

## 7. 운영 준비 (코드 밖)

1. 서비스 계정 생성과 `ADMIN` 부여 (5-3).
2. 렛츠커리어와 SSO `redirectUri` 재사용 협의 (5-2).
3. Vercel 프로젝트: Root Directory `apps/admin-mcp`, 환경 변수는 `apps/admin-mcp/README.md` 참고.
4. 도메인(예: `admin-mcp.ogonggo.co.kr`)과 `ADMIN_MCP_PUBLIC_ORIGIN`.
5. claude.ai 조직 설정 → 커넥터 → 맞춤 커넥터 추가 → `https://<도메인>/mcp`.

## 8. 미정·확인 필요

- 렛츠커리어 SSO `redirectUri` 재사용 허락 — 담당자 협의 필요.
- 쓰기 tool 을 열지, 연다면 BE 감사 로그를 먼저 둘지 — 미정.
- 부서 구성과 부서별 tool 목록 — 담당자 협의 필요.
