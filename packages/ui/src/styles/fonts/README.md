npm `pretendard` 패키지를 의존성으로 넣지 않고 파일만 받아 둔다. 패키지 전체는 97MB 이고
그 중 우리가 쓰는 것은 이 한 파일뿐이다.

버전을 올릴 때는 위 URL 의 버전 번호만 바꿔 같은 자리에 받고, 이 표의 버전과 크기를 함께 고친다.
